# Matt Pocock

TypeScript 領域專家、講師，以及知名開源專案 `mattpocock/skills` 的創作者。

## 重要事實
- **背景與聲譽**：在工程師社群中被視為 TypeScript 領域頂尖導師，許多開發者透過其教材精進技術 ([[grill-me-matt-pocock]])。
- **開源專案生態**：其開源專案 `mattpocock/skills` 在 GitHub 累計獲得逾 16 萬顆星，下載量達 700 萬次 ([[grill-me-matt-pocock]])。該專案主要以 `SKILL.md` 等 [[Markdown]] 文件構成，支援透過 `npx skills@latest add mattpocock/skills` 安裝與 `/setup-matt-pocock-skills` 初始化設定 ([[mattpocock-skills-repo]])。
- **五大技能體系架構**：將工程化開發流程劃分為五大模組：需求分析與規劃（如 `grill-me`）、測試驅動開發（如 `tdd`）、除錯與代碼審查（如 `diagnosing-bugs`）、架構改善（如 `improve-codebase-architecture`）及專案管理（如 `triage`）([[mattpocock-skills-repo]])。
- **核心開發哲學**：
  - 主張「極簡主義與模組化」，反對笨重僵化的防呆流程，認為單一 Skill 應專注解決單一問題，猶如即插即用的樂高積木 ([[grill-me-matt-pocock]])。
  - 主張將深厚的軟體工程老智慧（如深模組、經典重構壞味道、[[TDD]]）融入 Prompt 與架構設計，以駕馭 AI 黑盒子 ([[grill-me-matt-pocock]])。

## 與其他實體、概念的關係
- 創造了 [[grill-me]] 需求拷問模式與系列開發 Skills。
- 為 [[Claude Code]] 等終端機 Coding Agent 提供了一套完整的可執行工程方法論。
- 倡導在 AI 提示詞中應用 [[Skill 設計原則]]（Pruning、Signposts、明確完成標準）。
- 倡導在 AI 開發中嚴格落實 [[TDD]] 測試驅動機制以防止模型作弊。
- 實踐了 [[專案規則與技能工作流]]，將專案長期背景（`CLAUDE.md`）與動態操作手續（`SKILL.md`）清晰拆分。
- 提倡用 [[深模組與淺模組]] 理念對抗 AI 的淺模組生成傾向。
- 其模組化輕量工作流與 [[Superpowers]] 框架的長流程管線形成鮮明對比。

## 各來源怎麼說
- [[grill-me-matt-pocock]] 認為 Matt Pocock 真正開源的不僅是幾個工具，而是示範了在 AI 時代如何用深厚的專業思維和精煉語言去精準駕馭大型語言模型。
- [[mattpocock-skills-repo]] 強調其專案核心在於替 AI 程式助手安裝資深工程師的紀律與工程流程，而非單純給予模型模糊提示詞。
