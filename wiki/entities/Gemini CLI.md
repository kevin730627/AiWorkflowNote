# Gemini CLI

Google 提供或社群封裝的終端機命令行介面工具，允許使用者在終端機中直接調用 Gemini 系列大型語言模型進行文字生成與分析。

## 重要事實
- **終端機直連調用**：使用者可在本地終端機內直接下達指令，對本機檔案進行快速提問與摘要處理 ([[obsidian-github-backup]])。
- **批次處理能力**：可結合 Shell 腳本批次讀取資料夾內的 Markdown 筆記，自動執行週報整理、主題聚類或知識圖譜關聯建議 ([[obsidian-github-backup]])。
- **檔案層級共編**：與雲端對話視窗不同，CLI 工具直接作用於本機檔案系統，能與 [[Obsidian]] 的本地 Vault 無縫對接，使 AI 真正成為知識庫的共編者 ([[obsidian-github-backup]])。

## 與其他實體、概念的關係
- 作用於 [[Obsidian]] 的本機資料庫檔案。
- 依賴 [[Markdown]] 純文字的高通用性以理解與產出筆記內容。

## 各來源怎麼說
- [[obsidian-github-backup]] 認為將 Gemini CLI 深度整合到終端機與 Markdown 工作流中，展現了檔案層級人機協同的強大潛力。
