# Markdown

一種輕量級純文字標記語言，透過簡潔的符號語法實現結構化排版，並能在不同平台、編輯器與大型語言模型之間高效率流轉。

## 定義
一種用普通純文字格式編寫的文件格式，透過簡單符號（如 `#` 代表標題、`*` 代表強調、`-` 代表列表、`>` 代表引用）賦予文字格式結構，並能輕鬆轉換為 HTML 等富文本格式 ([[obsidian-github-backup]])。

## 在 AI 時代的戰略價值
- **大模型的天然語言**：幾乎所有現代大型語言模型（如 Gemini、GPT-4）皆以大量的 Markdown 資料進行預訓練，能零門檻、極其精準地解析與生成 Markdown 結構 ([[obsidian-github-backup]])。
- **人機共編介面**：相較於富文本（Rich Text）或二進位專有格式，Markdown 對人類而言直觀可讀可寫，對 AI 而言具備清晰的語意區塊邊界，是構建人機協作知識庫（LLM Wiki）的最佳基礎格式 ([[obsidian-github-backup]])。
- **長期保存性與跨平台**：文字格式永遠不會過期或損壞，可配合 Git 進行精確到每一行字元的差異比對（diff）與版本追蹤 ([[obsidian-github-backup]])。
