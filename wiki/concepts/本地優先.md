# 本地優先

一種軟體架構與資料管理哲學（Local-first），強調資料的所有權與主存儲必須始終位於使用者的本機裝置上，而非受制於遠端雲端伺服器。

## 定義
本地優先主張應用程式應將本機檔案系統作為單一事實來源（Single Source of Truth），雲端或遠端儲存庫僅作為同步、備份或協作的延伸管線。即便沒有網路或軟體服務商關閉，使用者仍對其數據保有完整掌控權 ([[obsidian-github-backup]])。

## 核心要點
1. **資料主權與隱私保護**：數據保存在本機硬碟，避免因雲端服務商營運危機、伺服器停擺或政策變更導致資料遺失或外洩 ([[obsidian-github-backup]])。
2. **無廠商鎖定（Vendor Lock-in）**：採用通用開放格式（如 [[Markdown]]），不使用專屬封閉資料庫格式，確保資料可在不同工具與編輯器間自由遷移 ([[obsidian-github-backup]])。
3. **自主同步與版本控制**：因檔案存於本機，使用者可依自身需求自主選擇同步手段，如 Git、私有 NAS（WebDAV）或雲端硬碟，並藉由 Git 獲得精準的版本歷史回溯能力 ([[obsidian-github-backup]])。
4. **AI 檔案層級存取**：本地檔案可被本機運行的 AI Agent 或 CLI 工具（如 [[Gemini CLI]]）直接讀取與處理，無需將整個知識庫上傳至受限的第三方雲端對話框 ([[obsidian-github-backup]])。
